## Descripcion
This [.tar file](https://challenge-files.cylabacademy.net/library/0fcc092f4e3d0027bc89f6de85e2b750462dca0a96c5643e38e5825e2da1c3d2/1000.tar) got tarred a lot.
## Solucion
1.- Organizar y ubicar el archivo inicial del reto en una carpeta de trabajo dedicada en la terminal:

Bash

```
cd ~/like
```

2.- Crear un script automatizado en Bash (`solve.sh`) para descomprimir los archivos `.tar` de forma iterativa desde el 1000 hasta el 1:

Bash

```
nano solve.sh
```

_(Pegar el código del bucle `while` que recorre los archivos en orden descendente)._

3.- Dar permisos de ejecución al script creado en el sistema:

Bash

```
chmod +x solve.sh
```

4.- Ejecutar el script para procesar toda la cadena de compresión de manera automática:

Bash

```
./solve.sh
```

5.- Verificar la extracción final del directorio, localizar la imagen resultante `flag.png` y abrirla para revelar la flag del reto.
