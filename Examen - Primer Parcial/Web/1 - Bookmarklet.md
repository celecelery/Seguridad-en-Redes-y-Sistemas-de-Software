## Descripcion
Why search for the flag when I can make a bookmarklet to print it for me?
## Solucion
- Entrar a la página web del reto
    
- Abrir el código de la página y copiar el script de JavaScript necesario para la solución
    
- Agregar la página actual a tus marcadores del navegador
    
- Editar el URL del marcador creado y reemplazarlo con el código de JavaScript obtenido
    
- Abrir el marcador desde la barra de favoritos para ejecutar el script y obtener la flag directamente
