## Descripcion
We made a lot of substitutions to encrypt this. Can you decrypt it?
## Solucion
- Entrar al link o archivo proporcionado por el reto para obtener el texto cifrado por sustitución
    
- Acceder a una herramienta en línea de resolución de cifrado por sustitución (como el _Substitution Solver_ de Quipqiup o equivalente)
    
- Ingresar el texto cifrado en la plataforma para realizar un análisis de frecuencia y autocompletado
    
- Ejecutar el proceso de resolución automática para descifrar el mensaje mediante sustitución monoalfabética
    
- Analizar el resultado devuelto para revelar el texto plano y completar la solución
