## Descripcion
In RSA d is a lot bigger than e, why don't we use d to encrypt instead of e?
## Solucion
- Acceder a la plataforma o servicio indicado por el reto para extraer los parámetros criptográficos disponibles
    
- Analizar el comportamiento del sistema y notar que el mensaje fue cifrado utilizando la llave privada (donde el exponente aplicado actúa como $d$ en lugar de $e$)
    
- Utilizar el exponente público estándar ($e = 65537$) junto con el módulo para revertir el proceso y descifrar el mensaje utilizando la clave pública
    
- Ejecutar la operación criptográfica correspondiente para procesar el texto cifrado y revelar el mensaje original en texto plano
