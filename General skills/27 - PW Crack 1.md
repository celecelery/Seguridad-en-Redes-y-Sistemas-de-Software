## Descripcion
Can you crack the password to get the flag?

Download the password checker [here](https://artifacts.picoctf.net/c/14/level2.py) and you'll need the encrypted [flag](https://artifacts.picoctf.net/c/14/level2.flag.txt.enc) in the same directory too.
## Solucion

```
celeh127-academy@webshell:~$ wget https://artifacts.picoctf.net/c/11/level1.py
celeh127-academy@webshell:~$ wget https://artifacts.picoctf.net/c/11/level1.flag.txt.enc
celeh127-academy@webshell:~$ nano level1.py
celeh127-academy@webshell:~$ python3 level1.py
Please enter correct password for flag: 1e1a
Welcome back... your flag, user:
picoCTF{545h_r1ng1ng_fa343060}
```
